## 自动阅读流程说明

### 职责

| 组件 | 职责 | 关键约束 |
| --- | --- | --- |
| `src/reader/run.js` `runOnce(config, options)` | 编排一次运行：连接浏览器、登录、选书、阅读、通知 | 返回 `{ status, minutes, error }`，`status` 为 `success` / `login-timeout` / `error` / `stopped`；不退出进程 |
| `src/reader/worker.js` | 阅读子进程入口：由面板 fork，经 IPC 接收配置、上报事件 | 收到 SIGTERM / SIGINT 或与面板断开时关闭浏览器后退出 |
| `src/reader/browser.js` | 连接配置中 Selenium 地址上的 Chromium，设置超时与随机窗口尺寸 | 隐式等待为 0；连接前在日志中记录 Selenium 状态与会话数（`src/shared/selenium.js`）；连不上时报错 `无法连接 Selenium（<地址>）：<原因>`；日志中的地址去掉用户名与密码 |
| `src/reader/login.js` | 打开首页、加载 cookies、展示二维码、等待扫码、保存 cookies | 按总时长等待，期间二维码过期就刷新 |
| `src/reader/reading.js` | 选书、切换上下滚动模式、阅读循环 | 每轮一次 `executeScript` 读取页面状态 |
| `src/reader/selectors.js` | 页面地址、定位器与关键文案 | 微信读书改版时只改这里 |
| `src/reader/timing.js` | 由配置得出各类等待时间与翻动间隔 | 测试可通过 `options.timing` 覆盖 |
| `src/reader/dom.js` | 显式等待与批量检查元素的工具函数 | 替代隐式等待 |

### 运行模式

| 模式 | 入口 | 行为 |
| --- | --- | --- |
| 阅读（默认） | 面板中“立即运行”、定时触发，或 `node src/cli.js run --account <id>` | 登录后选书并按阅读时长（`duration`）阅读 |
| 仅登录 | 面板中“仅登录”，或 `node src/cli.js run --account <id> --login-only` | 登录并保存 cookies 后结束，用于刷新登录态 |

两种模式也可以在面板中触发，由面板 fork 阅读子进程执行，见下文与 `docs/panel.md`“运行队列”。

### 流程

```mermaid
flowchart TD
  A[runOnce] --> B[createDriver]
  B --> C[打开首页并加载 cookies]
  C --> D{首页出现}
  D -->|登录入口| E[点击登录，截图并解析二维码，推送登录链接]
  D -->|我的书架| G
  E --> F{每秒检查一次}
  F -->|我的书架| G[登录成功，保存 cookies]
  F -->|二维码过期| H[点击刷新；失败则重新加载页面并再次打开登录弹窗]
  H --> F
  F -->|超过等待时长| T[login-timeout，发送失败通知]
  G --> I{模式}
  I -->|仅登录| S[success]
  I -->|阅读| J[选书并切换上下滚动模式]
  J --> K[阅读循环]
  K --> L[保存 cookies，发送完成通知]
  L --> S
```

### 阅读子进程与事件

面板为每次运行 fork 一个 `src/reader/worker.js`：面板发送 `{ type: "start", mode, config, screenshotDir, panelLink }`（`panelLink` 为配置了 `PANEL_PUBLIC_URL` 时该账号实时页面的地址，附在扫码推送中，否则为空），子进程调用 `runOnce`，并把运行中的事件以 `{ event, data }` 发回面板。日志写到标准输出，由面板保存为运行目录中的 `output.log`；阅读截图写入 `screenshotDir`（运行目录），cookies 与登录二维码仍在账号数据目录。

| 事件 | 时机 | `data` |
| --- | --- | --- |
| `started` | 子进程收到配置 | `version` |
| `session` | 浏览器会话建立 | `sessionId`，面板强制结束子进程时用它清理 Selenium 会话 |
| `login-required` | 每次截取二维码（含二维码刷新后） | `url`：解析出的登录链接，解析失败时为空 |
| `login-ok` | 登录成功（包括 cookies 仍然有效、不需要扫码时） | - |
| `login-timeout` | 等待扫码超时 | - |
| `book-opened` | 打开书并切换到上下滚动模式 | `title`：书名，取不到时为空 |
| `reading-minute` | 阅读中每分钟 | `minute`、`total`（计划分钟数）、`screenshot`（截图文件名，未开启截图时为空） |
| `done` | 完成（仅登录模式在保存 cookies 后） | `minutes` |
| `error` | 运行出错 | `message` |

`runOnce` 接收 `options.signal`（`AbortSignal`）。停止时立即关闭浏览器，正在执行的 WebDriver 命令随之失败，两次翻动之间、等待扫码的轮询等较长的等待也会立即结束；运行以 `stopped` 结束，不上报 `error`、不发送失败通知。浏览器正在连接时收到停止，连接完成后立即关闭。

### 阅读循环

每轮先等待一个随机翻动间隔，再用一次 `executeScript` 读取页面标题与各元素状态，然后按以下顺序处理：

| 顺序 | 条件 | 动作 |
| --- | --- | --- |
| 1 | 标题含“已读完”、出现“开通后即可阅读”或“全 书 完” | 打开目录，点第 2 个条目（只有一项时点这一项），回到书的开头附近 |
| 2 | “下一章”/“下一页”按钮完整出现在视口内 | 点击 |
| 3 | 出现“点击重试” | 点击 |
| 4 | 其他 | 按住方向键下 50–500 毫秒 |

每分钟截图一次（阅读期间每分钟截图，`screenshot`），文件名为 `screenshot-<分钟>.png`：由面板运行时写入运行目录，命令行运行时写入账号数据目录。截图小于 100KB 视为白屏并刷新页面：阅读页正文由 canvas 绘制，无法通过 DOM 文本判断是否白屏。刷新后如果回到了左右翻页模式，会重新切换到上下滚动模式。登录成功、阅读完成需要发邮件时另截一张图作为附件（`email-<事件>.png`），发送后删除，不计入阅读截图。

某一轮遇到章节切换、页面局部重绘时常见的瞬时错误（元素已失效、页面脚本执行环境被销毁、元素被遮挡或不可点击等），会记一条警告并跳过这一轮；连续超过 3 轮仍出错时才按运行出错结束。其他错误（如浏览器会话已断开）仍立即结束。

### 翻动节奏

| 阅读速度（`speed`） | 翻动间隔 |
| --- | --- |
| `slow`（默认） | 13–19 秒 |
| `normal` | 8–12 秒 |
| `fast` | 4–8 秒 |

旧版设置了 5 秒隐式等待，每轮对不存在元素的检查都会被拖慢，实测每轮 10–15 秒，上游 `WEREAD_SPEED` 原有的 0.1–1 秒随机间隔实际上不起作用。现在去掉了隐式等待，翻动节奏完全由上表决定，默认的 `slow` 与旧版的实际节奏接近。

### 关键约束

| 约束 | 说明 |
| --- | --- |
| 隐式等待为 0 | 元素不存在时立即返回；需要等元素出现的地方（首页入口、书架、切换按钮、目录条目）使用显式等待 |
| 等待扫码 | 由等待扫码时长（`loginTimeout`，分钟，默认 15）控制；二维码约 1 分钟过期，期间自动刷新，不限次数。首页在等待时间内没有出现“登录”入口或书架时刷新重试一次，仍没有就以错误结束；点击“登录”后找不到二维码时刷新页面重试一次，仍没有就以错误结束，不进入等待 |
| cookies | 先写临时文件并刷到磁盘再重命名，权限 0600（登录二维码图片同样为 0600，账号数据目录 0700）；读取时内容损坏则改名为 `cookies.json.corrupt-<时间戳>` 并转入扫码；单个 cookie 加载失败只跳过该条 |
| 登录二维码 | 只认登录弹窗中可见的二维码图片或扫码提示（首页书籍封面的图片地址也含有“qr”，不能按地址匹配）。`login.png` 为整页截图，`login-qr.png` 为二维码区域截图（用作邮件附件；解析不出登录链接时面板显示这张截图）；弹窗中还没有二维码图片时删除 `login-qr.png`，面板改为显示整页截图；解析不出登录链接且配置了面板地址时，推送面板链接 |
| 书架选书 | 只点击首页书架中带链接的书籍卡片：刚登录时书架仍在加载，只有 4 个不含链接的占位卡片，点击无效；公众号文章打开的阅读页没有目录按钮，不计入第几本。点开后在页面等待时长内未出现「目录」按钮时报错，错误中带当前页面地址 |
| 首页校验 | 首页标题不是“微信读书”时报错 |
| 书名 | 从阅读页标题“书名 - 作者 - 微信读书”中解析，取不到时为空 |
| 日志 | `util.format` 格式化；`console.debug` 只在开启调试日志（`debug`）时输出 |
| 登录链接 | 在有效期内可用于完成这次登录，不写入日志，日志中只记录“已解析登录链接”。由面板运行时经 `login-required` 事件交给面板显示；命令行运行（`run --account`）时在终端显示登录链接与二维码，只输出到终端，不写入 `output.log` |
| 密钥 | 日志中不打印 Bark Key 等密钥；面板保存运行日志前还会把密钥值与登录链接中的 uid 替换为掩码，见 `docs/panel.md`“运行队列” |
| 停止 | 面板中停止或进程收到 SIGTERM / SIGINT 时关闭浏览器后结束，见“阅读子进程与事件” |
