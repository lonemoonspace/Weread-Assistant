## 面板页面验收用例

`scripts/ui-smoke.js` 启动面板（用桩子进程 `scripts/fixtures/stub-worker.js` 代替阅读子进程，Selenium 地址指向模拟的 Selenium `scripts/fixtures/mock-selenium.js`，预先写入本月的运行记录、调度规则与月卡挑战），用浏览器走通各页面并截图，不访问微信读书。执行方式：`SELENIUM_URL=<Selenium 或 chromedriver 地址> npm run test:ui`，截图目录见输出。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| smoke 自查 | 执行 `npm run test:ui` | 17 项全部通过并退出码 0 |
| 登录与总览 | 先输入错误密码，再输入正确密码 | 显示“密码错误”；登录后总览顶部的 Selenium 状态为“就绪”、已用 0/1 个会话，没有 noVNC 链接；有 3 个账号卡片，显示今天的阅读分钟、打卡状态与下次运行时间 |
| Selenium 状态 | 模拟 Selenium 的会话被占用后点“刷新”；节点改为不可用后点“刷新”；停止模拟 Selenium 后点“刷新”；重新启动后点“刷新” | 占用时显示“会话已满”与“其中 1 个会话不属于面板正在进行的运行”；节点不可用时提示“Selenium 未就绪：Selenium Grid not ready。”；停止后卡片变红，标签为“无法连接”，提示“无法连接 Selenium：连接被拒绝”与 `docker compose up -d selenium`；恢复后为“就绪”且不再提示 |
| 扫码 | 在“扫码测试”卡片上点“仅登录” | 总览顶部出现该账号的二维码（`data:image/gif`，浏览器本地生成）与“复制登录链接”；实时页面同样显示二维码；点“停止”后状态为已停止 |
| 实时 · 完成 | 在“小明”的实时页面点“立即运行” | 状态变为成功，显示最新截图与实时日志（从“加入队列”到“运行结束：成功”） |
| 实时 · 阅读中 | 在“长时间阅读”的实时页面点“立即运行”，再点“停止” | 显示“正在读《测试书》第 N/68 分钟”与进度条；停止后状态为已停止 |
| 历史 | 打开“小明”的历史页面，展开截图与日志 | 第一行为刚才的运行（成功）；截图图片加载成功；日志含 `[PANEL]` 行并可下载 |
| 打卡日历 | 打开“小明”的打卡日历 | 显示 7 列星期、本月每天的分钟数，已打卡的日期为绿色，今天有边框；显示月卡进度（第几天、已打卡天数、累计小时） |
| 调度 | 添加一条每天 07:30 的规则，预览后保存 | 预览显示“每天 07:30：接下来 …”；保存后提示立即生效，接口中有 3 条规则 |
| 配置 | 打开“阅读时长”的“单独设置”，填 30 并保存；发送测试通知 | 接口中账号覆盖的阅读时长为 30；测试通知提示“没有配置任何通知渠道” |
| 设置 | 并发数改为 2，填写 noVNC 地址；全局阅读时长 68、填写 Bark Key 并保存；修改面板密码 | 填写 noVNC 地址前没有安全提示，填写后出现提示（含 `SE_VNC_PASSWORD`、`SE_VNC_VIEW_ONLY=1`）；接口中设置与默认配置已更新，Bark Key 只返回掩码，表单显示“已设置，留空不修改”；密码修改成功，新密码可以登录 |
| noVNC 与并发提示 | 回到总览；之后在“长时间阅读”的实时页面运行到阅读中 | 总览的 Selenium 卡片中有“查看浏览器画面（noVNC）”链接，地址为设置的值，`target="_blank"`、`rel="noopener noreferrer"`；并发数 2 而 Selenium 只有 1 个会话，提示“只有 1 个会话”；实时页面阅读中时状态行显示 noVNC 链接 |
| 新建与删除账号 | 新建 `new-1`，在配置页删除并确认 | 创建后进入该账号的实时页面并提示扫码；删除后回到总览，账号已不存在 |
| 断线重连 | 服务端断开所有连接 | 页面顶部提示“实时连接已断开”，随后自动重连；之后启动的运行在页面上照常更新 |
| 断线期间结束的运行 | 新账号的实时页面中运行到“阅读中”后，服务端断开所有连接并立即停止该运行，等待页面自动重连 | 重连后实时页面显示这次运行的结果“已停止”与完整日志（含“运行结束：已停止”），而不是“当前没有运行” |
| 控制台 | 以上操作全程 | 除了故意输错密码产生的一条 401，浏览器控制台没有错误与警告（包括 CSP 拦截） |
| 退出 | 点“退出” | 回到登录页 |
| 手机宽度 | 以 390px 宽度登录，依次打开总览（含 Selenium 状态、并发提示与二维码）、实时、历史、日历、调度、配置、设置 | 各页面没有横向滚动，控制台没有错误与警告 |
| 真实部署 | 在树莓派上以 compose 部署，经反向代理访问，完成扫码、阅读、停止、调度触发各一次 | 页面状态与实际运行一致（第 10 步真机验收） |
